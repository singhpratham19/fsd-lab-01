# FSD Lab Assignment 1: Blog Post Layout

A responsive single-page blog built with HTML5, CSS and Bootstrap 5.

- Inline CSS: post title
- Internal CSS: author name
- External CSS: `style.css`, using tag, class and ID selectors

Open `index.html` in a browser. An internet connection is needed for Bootstrap and the fonts.
